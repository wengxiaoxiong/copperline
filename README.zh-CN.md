# react-gta · Copperline

[English](README.md) · [法律与署名说明](docs/LEGAL.md)

一个基于浏览器的第三人称小型沙盒：可以开车、开枪、捡金币，街区根据种子在玩家周围持续生成。**Copperline（铜线街区）**是游戏名称，`react-gta` 是仓库名称。

画面参考早期主机游戏的氛围：暖色夕阳、低清旧纹理、独栋住宅、棕榈树和紧凑 HUD。这是独立原型，不是 GTA 官方产品，也没有使用原版游戏的地图或提取素材。

> **技术栈说明：**虽然仓库名包含 `react`，当前实际使用的是 **Three.js + TypeScript + Vite + Rapier**，界面采用 HTML/CSS，尚未引入 React。

## 本地运行

需要 Node.js **22.13+**、npm，以及支持 WebGL 2 的桌面浏览器。

```sh
git clone https://github.com/wengxiaoxiong/react-gta.git
cd react-gta
npm ci
npm run dev
```

打开 Vite 输出的地址，通常是 `http://localhost:5173/`，点击「进入街区」。当前游戏界面为中文。

游戏只有在浏览器授予 **Pointer Lock（鼠标锁定）**之后才开始，此时鼠标隐藏，并使用相对位移控制瞄准。如果内置浏览器拒绝请求，请在 Chrome 或 Edge 中打开同一地址后再次点击。Esc 暂停并释放鼠标。网页不能绕过浏览器或操作系统对鼠标锁定的限制。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动／油门、倒车、转向 | WASD |
| 跑步（约步行的 2.5 倍速） | Shift |
| 跳跃／驾驶时手刹 | 空格 |
| 上下附近的车／抢车 | F；车辆需停下或低速，下车前需先减速 |
| 射击／肩后瞄准 | 鼠标左键／右键 |
| 换弹 | R |
| 暂停、释放鼠标 | Esc |
| 返回附近道路 | V |
| 打开／关闭大地图 | M；滚轮缩放、拖动平移、点击道路导航 |
| 第一／第三人称视角 | C |
| 静音／恢复声音 | N |

出生点前方有一辆橙色轿车。步行或驾驶经过金币都能拾取；被击倒的行人也会掉落金币，记得在区块卸载前开过去或走过去捡走。红色路边靶标普通命中三次后倒下。MR-17 弹匣容量为 30 发，备用弹药无限，但保留换弹时间。

街道现在是敌对的：约 34 米内的行人会冲向玩家并近身攻击，扣减弹药条上方的生命条；生命归零后玩家会被送回附近道路并恢复生命。行驶中的车流和玩家自己的车都能把人碾倒，被碾到的行人会死亡并掉落金币。

## 已实现

- 第三人称移动、镜头避障、肩后瞄准和驾驶跟随。按住 Shift 跑步约为步行速度的 2.5 倍。
- 所有附近车辆可上车，NPC 车辆支持短暂开门、司机下车逃跑和控制权转移。接管后保留同一辆车的颜色、刚体和位置，下车后可再次驾驶。
- 行人具有生命值、枪声惊慌、受击和倒地状态，被击倒时掉落可拾取的金币；附近行人会转为敌对，追击玩家并近身攻击，被行驶车辆碰到即被碾倒。射击同时检查建筑、地面、车辆和行人的遮挡，使用独立的相机瞄准与枪口射线。
- 世界种子先确定海岸、河流、丘陵、连通道路和桥梁，再沿道路生成建筑。住宅、商业、老城、中心、港口、河畔、山地和海滨有不同密度与外观；地标包括水塔、灯塔、港口吊机和广场。
- 72 米区块只用于加载，附近保留 7 × 7 个区块；道路可以弯曲并跨区块连接。地面与桥面有真实碰撞，车辆按路面坡度调整姿态。
- 大地图与小地图共用世界数据。大地图支持缩放、拖动、玩家定位、已驾驶车辆标记和沿道路导航；打开时暂停游戏并释放鼠标，返回时重新请求鼠标锁定。
- 本次游戏已改变的 NPC、车辆、金币和靶标状态在回访时保留；刷新或重新开始会重置。

## 当前边界

这是低多边形沙盒原型。当前种子生成的是一座约 1.5 公里宽的海滨城市，外围地面可继续加载，路网有边界；并非无限延伸的城市路网。还没有警察追捕、多人、建筑内部、剧情、游泳和车内射击。驶入深水后会返回附近道路。

人物动作与车辆操控经过简化，车流按道路行驶、避让和等待路口；没有复杂驾驶决策。静音键已从 M 改为 N。时钟与装饰状态条仍是视觉元素。

近处资源随区块卸载；已接管车辆和改变过的 NPC 状态会随本次游戏累积，不保证无限时长运行时总内存恒定。游戏无需后端，字体请求失败时使用本地回退。

## 构建与验证

```sh
npm test
npm run build
npm run preview
```

构建包含 TypeScript 检查，输出的 `dist/` 可用于静态托管。

18 项自动测试覆盖确定性生成、道路连通和导航、道路与地标避让、可达金币、桥面碰撞、负坐标、扫掠拾取、武器时序、NPC 命中与状态保留、车辆接管与加载边界、地图暂停和鼠标锁定失败重试，以及连续射击时的镜头稳定。

`scripts/city-scenario.js` 在开发页面的 `window.__game` 上运行实际 `Game` 方法与 Rapier 物理：

- `cityScenario(game)` 检查上车、驾驶、下车、抢车、司机逃跑、真实射击和大地图导航。
- `roadDrivingScenario(game)` 检查约 155 米坡道与 139 米桥面通行。
- `cityRouteScenario(game)` 分批推进住宅→商业→河畔→港口→海滨路线；后续调用传 `true` 继续，直到返回 `done: true`。已跑通约 1.55 公里，附近保持 49 个加载区块。这个道路检查清除普通车流以隔离道路碰撞问题。

这些脚本会主动摆放场景，只用于开发验收，**不等于实时帧率或完整键鼠游玩验收**。当前内置浏览器拒绝鼠标锁定；启动失败与重试边界已测试，实际游玩建议使用 Chrome / Edge。旧的 `scripts/browser-scenario.js` 保留了原方格地图的检查，不适用于新路网。
